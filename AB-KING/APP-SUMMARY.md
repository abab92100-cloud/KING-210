# 🏆 KING-trading — الملخص الشامل للتطبيق

> بوت تداول عقود آجلة (Futures) يعمل على أندرويد — يتصل مباشرة بمنصة KuCoin Futures ويتداول آليًا بشكل مستمر، مع محرك ذكاء، استخبارات سوق حية، وبقاء في الخلفية لا ينقطع.
>
> **اسم التطبيق:** KING-trading · **المعرّف:** `com.abking.trading` · **الإصدار الحالي:** v1.0.5+

---

## 1) نظرة عامة

| البند | التفاصيل |
|---|---|
| النوع | تطبيق جوال (أندرويد) — Capacitor + React + TypeScript |
| المنصة المستهدفة | KuCoin Futures (عقود USDT الدائمة) |
| وضعا التشغيل | **ورقي (Paper)** للمحاكاة · **LIVE** للتداول الحقيقي بمفاتيح API |

## 2) شاشات التطبيق (5 شاشات)

### 🏠 الرئيسية (Home)
- السعر اللحظي + المارك + الإنديكس للعملة الحالية
- حالة البوت (يعمل/متوقف/يدرس) + عدّاد النبضات
- الصافي الحالي: أرباح محققة + غير محققة − رسوم − انزلاق − **رسوم التمويل الموقّعة**
- آخر السجلات والقرارات لحظة بلحظة

### 📡 الرادار (Radar)
مسح شامل لكل عقود المنصة (حتى 691 عقدًا) وترتيبها بدرجة ملاءمة لاستراتيجية الشبكة، مع بيانات حية لكل عقد:
- **درجة الملاءمة** (0-100): تذبذب مثالي + سبريد ضيق + سيولة + سعر مناسب لرأس المال
- **التمويل السنوي** (`fundAnnPct`): كم يدفع/يتلقى حامل المركز
- **OI بالدولار**: قيمة المراكز المفتوحة الكلية
- **basis**: انحراف المارك عن الإنديكس (يعود دائمًا — إشارة قوية)
- **المدى اليومي** (`rangePct`): أفضل أهداف الشبكة
- **تصنيف الانحراف**: 🔴 لونغ متكدس / 🟢 شورت متكدس

### 🧠 استخبارات السوق (بطاقة داخل الرادار)
لوحة موحدة من كل المسح، تُحدَّث كل 3 دقائق:
- **🔥 انضغاط لونغ**: تمويل مرتفع + صعود حاد (حذر الانعكاس)
- **💫 مرشح انعكاس صاعد**: شورتات متكدسة تدفع تمويلًا سالبًا
- **أعلى/أدنى تمويل سنوي** الآن
- **أكبر 5 مراكز مفتوحة** (OI)
- **🎯 أوسع مدى يومي**: أفضل 5 أهداف لشبكة الجنريل
- **⚖️ أقصى انحراف مارك/إنديكس**: فرص عودة إحصائية

### 📊 المراكز (Positions)
- المركز الحالي: الاتجاه، الحجم، الدخول، الصافي الطافي لحظيًا
- مستويات الجنريل المسلّحة والتنفيذ
- الرصيد، الرافعة، رسوم المنصة الفعلية المقروءة من العقد

### 📜 السجل (Journal)
- سجل كل الصفقات المنفذة بالأرباح/الخسائر الصافية
- إحصائيات متعلمة: نسبة النجاح، متوسط الربح/الخسارة، أطول سلسلة خسائر

### ⚙️ الإعدادات (Settings)
- ربط مفاتيح KuCoin (API Key/Secret/Passphrase) لوضع LIVE
- رأس مال الدورة، الرافعة، عدد مستويات الشبكة، خطوة الشبكة %
- هدف الربح الصافي للمجموعة (`tpNet` بصافي $)
- الصبر (ساعات/دولار) قبل التصحيح
- الأصوات والنغمات والاهتزاز

## 3) محرك التداول — المنطق الكامل

### الاستراتيجية الأساسية: شبكة جنريل متدرجة
- يبني مستويات شراء/بيع حول السعر بدرجة اتجاه محسوبة تلقائيًا (`directionMode: auto`)
- كل مستوى مرتبح يُغلق بصافي مستهدف فوق الرسوم — لا يغلق مركزًا أبدًا بخسارة إلا بجنريل مؤكد
- **الربح الوحيد**: صافي $0.12 للمجموعة (وضع عادي) — أوصافافي $0.03 (وضع HF عالي التردد)

### صيد الفجوات (Gap Hunter) — وضع اختياري
- المبدأ: سعر KuCoin ينحرف إحصائيًا عن الإنديكس (المركب من 5 منصات)
- عند انحراف z < −2σ: ضغط محلي يعود للإنديكس — ندخل مع العودة
- **القياس المخبري الموثق: 63% نجاح، +66% على 8 أيام / 10 عملات**

### الذكاء التكيفي
- **دراسة البسمة**: قبل الدخول لعملة جديدة يدرس 15-30 دقيقة (شموع 1 دقيقة) لالتقاط الإيقاع
- **الذاكرة التعلمية** (`S.memory`): إحصائيات ربح/خسارة لكل عملة — العملات الخاسرة تُهمَّل تدريجيًا
- **التبديل الذكي**: بعد إغلاق مركز، إن كانت عملة أخرى أقوى بفارق واضح يقترح/ينفذ التبديل
- **نقاط الاصطياد** (`huntPct`): شراء جزئي عند حركة مفاجئة عكس الاتجاه لتحسين متوسط الدخول

### إدارة المخاطر
- كل أمر `reduceOnly` للجنريل (لا توسيع عرضي)
- بنك جزئي للجنريل (`_tpBanked`) — لا يجمع أبدًا مرتين
- رسوم فعلية من المنصة: `makerFee 0.02%` / `takerFee 0.06%` (تُقرأ لكل عقد)
- **رسوم التمويل الموقّعة**: اللونغ يدفع عند التمويل الموجب ويتلقى عند السالب — والعكس للشورت (الحساب الحقيقي الكامل)
- الانزلاق المتعلم (`learnSlippage`): يقيس الانزلاق الفعلي ويضمّنه بالأهداف

## 4) طبقة الاتصال — لماذا لا ينقطع (بعد الإصلاحات الثلاثة)

| الطبقة | ما تعمل | ملاحظة |
|---|---|---|
| **WebSocket مباشر** (`ws.ts`) | سعر + دفتر + صفقات لحظيًا عبر `bullet-public` | نبض ping/pong حسب مواصفات KuCoin |
| **مراقب شبكة أندرويد أصلي** (Java) | `ConnectivityManager.NetworkCallback` | حدث نظام — يعمل حتى في الخلفية العميقة |
| **استماع JS** (`online`/`offline`) | إعادة وصل فورية عند عودة النت + فحص دوري | احتياطي للمتصفح |
| **خدمة أمامية حقيقية** | إشعار "KING يعمل" دائم + `dataSync` type | أندرويد لا يقتل التطبيق + يظهر في إعدادات البطارية |
| **قفل معالج + START_STICKY** | WakeLock يعاد انتزاعه بالنبضة + الخدمة تُعاد إن قُتلت | بقاء مطلق |

سلسلة الإصلاحات الموثقة (كلها مجرّبة في CI وبناء ناجح):
1. إعادة وصل فورية + إيقاف المحاولات أثناء الانقطاع (JS)
2. مراقب Java أصلي يعمل في الخلفية (`startWatchdog` حقيقي)
3. إصلاح **الخدمة الأمامية التي لم تكن تبدأ أصلًا** (إعلان `<service>` مفقود في Manifest — السبب الجذري للقتل)
4. إصلاح انبعاج الإقلاع (`addListener` قد يرجع كائنًا لا Promise)

## 5) البيانات المستخدمة من المنصة (نتيجة البحث العميق)

المختبر (`backtest/discoverlab*.mjs`) جرب 20 نقطة نهاية عامة وحصر **124 حقل بيانات فريدًا** — كان التطبيق يستغل 17 فقط، والآن يستغل أقوى الإشارات المكتشفة:

- **التمويل**: `fundingFeeRate`, `fundingRateGranularity`, `nextFundingRateTime`, `predictedFundingFeeRate`
- **التراكم**: `openInterest` (قيمة بالدولار), `oiToVolPct` (نسبة OI للحجم)
- **الانحراف**: `markPrice` vs `indexPrice` → `basisPct` (أقوى إشارة — تعود بالتصميم)
- **المدى**: `highPrice/lowPrice` → `rangePct` (أهداف الشبكة)
- **المواصفات**: `multiplier`, `tickSize`, رسوم فعلية, `maxLeverage`
- **التحقق المخبري**: الحسابات صحيحة لـ **691/691 عقدًا نشطًا**

## 7) التشغيل (3 خطوات — بلا أي أوامر)

1. **ثبّت** `AB-KING-latest.apk`
2. افتح ← أدخل مفاتيح KuCoin من الإعدادات (لوضع LIVE) أو ابدأ ورقيًا
3. اضغط **Start** ← يظهر إشعار "KING يعمل" الدائم ← اضبط البطارية على **"غير مقيد"** أول مرة

> البوت يتصل بالمنصة مباشرة، يعيد الاتصال فورًا عند أي انقطاع، ويبقى حيًا في الخلفية — كله داخل التطبيق.
>
> **سيرفر Termux اختياري تمامًا** — طبقة موثوقية إضافية فقط لمن يريدها (`releases/king-setup.sh`).

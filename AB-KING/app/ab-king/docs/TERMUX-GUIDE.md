# KING Trading — دليل التشغيل الكامل

## أولًا: تحميل التطبيق ودمج التحديث

من صفحة الـ Release على GitHub، نزّل الملفات:

| الملف | ماذا يعمل |
|---|---|
| `king-server.mjs` | سيرفر الجوال (العقل الدائم للبوت) |
| `king-setup.sh` | مثبّت تلقائي بأمر واحد |
| `king-web.zip` | نسخة الويب الكاملة (لو أردت استضافة/تجربة على المتصفح) |

---

## ثانيًا: تجهيز Termux (مرة واحدة فقط)

1. ثبّت تطبيق **Termux** من F-Droid (نسخة Play Store قديمة ومحظورة من التحديث — استخدم F-Droid).
2. افتح Termux وشغّل:

```bash
pkg update -y
pkg install -y curl nodejs-lts termux-api
```

---

## ثالثًا: تشغيل السيرفر (الأمر الواحد)

انسخ هذا الأمر كاملًا والصقه في Termux:

```bash
curl -sL https://github.com/abab92100-cloud/King/releases/latest/download/king-setup.sh | bash
```

هذا الأمر يقوم تلقائيًا بكل شيء:
- يثبّت Node.js إن لم توجد
- ينزّل أحدث نسخة من السيرفر إلى `~/king/`
- يفعّل `termux-wake-lock` (منع نوم المعالج)
- يشغّل السيرفر مع **حارس إعادة تشغيل تلقائي** — إن سقط لأي سبب يعود خلال 3 ثوانٍ

---

## رابعًا (إلزامي مرة واحدة): إعدادات أندرويد حتى لا يتوقف السيرفر

بدون هذه الخطوة سيقتل أندرويد السيرفر بعد ~30 دقيقة في الخلفية:

1. **إعدادات الجوال ← التطبيقات ← Termux ← البطارية** ← اختر **«غير مقيد / Unrestricted»**
2. في **«العناية بالبطارية»** أضف Termux إلى قائمة **«التطبيقات التي لا تُثبَّط أبدًا»**
3. عطّل تحسين البطارية لتطبيق **KING** نفسه أيضًا (نفس الخطوات)

---

## خامسًا: التشغيل اليدوي (بعد أول تثبيت)

السيرفر يعمل الآن في نافذة Termux. لاحظ: **أبقِ هذه النافذة كما هي** — لا تغلقها بمسحها من التطبيقات الأخيرة، لكن يمكنك تصغيرها.

للتشغيل يدويًا في أي مرة:

```bash
cd ~/king
node king-server.mjs
```

أو مع الحارس (إعادة تشغيل تلقائية عند أي سقوط):

```bash
cd ~/king
while true; do node king-server.mjs; sleep 3; done
```

### التشغيل الصامت الدائم (بلا نافذة)
لتشغيل السيرفر دون إبقاء جلسة Termux مفتوحة، ثبّت `termux-services`:

```bash
pkg install -y termux-services
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/king-server.sh <<'EOF'
#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
cd $HOME/king
while true; do node king-server.mjs; sleep 3; done
EOF
chmod +x ~/.termux/boot/king-server.sh
```

بهذا يعمل السيرفر **تلقائيًا مع كل إعادة تشغيل للجوال**.

---

## سادسًا: ربط التطبيق بالسيرفر

1. افتح تطبيق **KING Trading** على الجوال
2. سيتصل تلقائيًا بالسيرفر المحلي (`127.0.0.1:8787`) وستظهر شارة **«سيرفر»** — يعني العقل يعمل في الخلفية حتى لو أغلقت التطبيق
3. من **الإعدادات** أدخل مفاتيح KuCoin (أنشئ مفتاحًا بصلاحية «تداول فقط» بدون سحب)
4. حدد الزوج والرافعة (×1–×100 كما تريد) وابدأ

---

## أوامر مفيدة

| الأمر | الوظيفة |
|---|---|
| `node king-server.mjs` | تشغيل السيرفر مباشرة |
| `curl http://127.0.0.1:8787/health` | فحص أن السيرفر حي (يرد `{"ok":true}`) |
| `curl http://127.0.0.1:8787/state` | رؤية حالة البوت كاملة من الطرفية |
| `pkill -f king-server.mjs` | إيقاف السيرفر |
| `cat ~/.king/king-server-store.json` | عرض الحالة المحفوظة (تنجو من إعادة التشغيل) |

---

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «لا يصل الجوال إلى GitHub» | تحقق من الإنترنت ثم أعد الأمر |
| السيرفر يتوقف بعد نصف ساعة | لم تُطبَّق خطوة «غير مقيد» في إعدادات البطارية — طبّقها لـ Termux وKING |
| التطبيق لا يجد السيرفر | تأكد أن Termux يعمل ونفّذ `curl http://127.0.0.1:8787/health` |
| انتهت مساحة أو أخطاء تحديث | `pkg update -y && pkg upgrade -y` ثم أعد التشغيل |
